# Как движок рисует свет

Откройте `index.html` двойным щелчком в Edge, Chrome или Firefox. Интернет, установка пакетов и локальный сервер не нужны. Для переноса статьи достаточно одного `index.html`: изображения, CSS, JavaScript и SVG встроены в него.

В статье 22 главы, реальные кадры существующей сборки, авторские схемы, графики формул и два интерактивных примера. Глава 03 объясняет indirect draw, instancing и bindless geometry. Глава 04 разбирает Tessy, построение кластерного DAG и выбор его разреза. Есть поиск по тексту глав в оглавлении, тёмная тема, увеличение шрифта и оформление для печати через Ctrl+P. При отключённом JavaScript текст и статические иллюстрации остаются доступны.

Ссылки на C++/HLSL работают из исходного расположения `docs/rendering_article` внутри репозитория. После переноса HTML они могут быть недоступны; это не мешает чтению. Ссылки на внешние первоисточники требуют интернета только при переходе по ним. Используются системные Georgia, Segoe UI и Consolas с запасными семействами; загрузок шрифтов из сети нет.

## Происхождение

Основной текст основан на рабочей копии test_cube от 3 ноября 2026 года, включая незакоммиченные изменения. Главу о Tessy сверили с кодом на 9 ноября 2026 года. Кадры сделаны `x64/Release/test_cube.exe` без пересборки и не являются сравнительными измерениями качества. Графики и интерактивные модели подписаны как учебные. Ведомость авторов ассетов из CREDITS.md включена в HTML.

## Пересборка статьи

`python docs/rendering_article/build_article.py`

Нужны Python 3 и Pillow. Скрипт читает `article.css`, `article.js`, `assets/*.png` и корневой `CREDITS.md`; создаёт самодостаточный `index.html`. Исходные файлы движка и уровни не изменяются.

Кадры: `coast.png` — 15:00, камера уровня; `island.png` — 18:00, позиция (-75, 28, 40), quaternion (0.119691, 0.491735, -0.068457, 0.859758); `room.png` — 00:00, позиция (-24.90, 1.35, 89.34), quaternion (-0.0431, -0.4556, -0.0221, 0.8889). Общие параметры: wind_test, 1600×900, `--time-freeze --wind-freeze=0 --no-hud`. Ожидание снимка: 6–7 секунд.
